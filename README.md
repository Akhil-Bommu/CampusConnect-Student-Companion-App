# CampusConnect-Student-Companion-App
# Abstract

**CampusConnect** is a Flutter-based mobile application created to make everyday student activities easier to manage in one place. It brings together useful features such as college events, announcements, and personal tasks through a simple and easy-to-use interface.

Students can view upcoming events, check announcements, add and manage tasks, and mark completed tasks. The application also uses a REST API to fetch and display dynamic announcement data.

The project focuses on practical Flutter and Dart concepts such as widgets, responsive layouts, navigation, forms and validation, state management, custom widgets, themes, and animations. Provider is used to manage application state and keep the app organized.

CampusConnect is mainly built as a hands-on learning project to understand how different Flutter concepts work together to create a functional mobile application. It also provides a strong foundation for building more advanced Flutter applications in the future.
